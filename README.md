# Studio Print — Formação de preços

Calculadora de preços de impressão 3D e criação de orçamentos para WhatsApp.

Site oficial: https://douglassistemas2010.github.io/Studio_print/

HTML autossuficiente em `index.html`, com bibliotecas e logo incorporadas. Hospedagem GitHub Pages a partir da raiz da branch main.

Os dados do aplicativo ficam no navegador de cada dispositivo; não são sincronizados pelo GitHub. Para levar dados do HTML local ao site, use Backup dos dados e Restaurar backup.

Inclui cálculo de custos, markup, referências, gráficos animados, orçamento com logo e compartilhamento no WhatsApp.
